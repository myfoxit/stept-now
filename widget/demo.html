Acme Inc. — demo host page

A plain website embedding the Stept widget + product tours.

Getting a widget key: this page reads the key from ?key=wk_… in the URL. Grab the seeded demo key from the default “Website widget” inbox — in the dashboard it’s shown as the embed snippet (Inbox settings), or run make seed and copy the widget_key of that inbox from the DB / GET /api/v1/w/{ws}/inboxes. Then open demo.html?key=wk_your_key&api=http://localhost:8600.
